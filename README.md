# Mi Página Personal

## Descripción
Página web personal creada para la asignatura Diseño de Sistemas en Internet.

## Objetivo general
Identificar la estructura básica del frontend mediante HTML, organizando correctamente los elementos de una página web.

## Contenido
- Encabezado principal con mi nombre.
- Párrafo de presentación personal.
- Lista de intereses y habilidades.
- Imagen obtenida de Internet.
- Enlaces a sitios web favoritos.

## Tecnologías utilizadas
- HTML
- CSS
- Visual Studio Code
